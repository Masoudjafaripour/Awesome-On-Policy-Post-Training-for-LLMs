# Awesome On-Policy Post-Training for LLMs

A curated collection of papers, code, surveys, benchmarks, and educational resources on **on-policy post-training** for Large Language Models (LLMs), including **online SFT**, **self-distillation**, **on-policy distillation**, **RLHF**, **RLVR**, **verifier-guided learning**, **search-based learning**, and **reasoning-oriented training**.

> The focus of this repository is how modern reasoning models are trained *after pretraining* using data generated by themselves, teachers, verifiers, search procedures, or reinforcement learning.

## Overview

Modern reasoning models are typically trained through multiple post-training stages:

```text
Pretraining
    ↓
SFT
    ↓
Distillation
 ├── Offline Distillation
 ├── Self-Distillation
 └── On-Policy Distillation
    ↓
RLHF / RLVR
    ↓
Reasoning Models
```

This repository focuses on methods where training data is generated online from the current policy:

[
\tau \sim \pi_\theta
]

and improved through supervision, verification, search, or reinforcement learning.
